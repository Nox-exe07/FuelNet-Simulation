How it Works

  1. Physics prior: Base = FC × 23.7 (stoichiometry: 2.31 kg CO₂ per L gasoline per 100km → 2310/100×?)
  2. Residual MLP: FuelNet predicts residual CO2 − FC×23.7 — easier to learn, explains R² 0.992.
  3. Pipeline: LabelEncode categoricals → StandardScale → 10-dim → 512→1024 + 3×ResidualBlock → 1.
  4. Real-time: Canvas loop at 60fps, fuel integral Σ FC·dt, CO₂ integral, particle spawn ∝ CO₂/400.
